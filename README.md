# Projecto Pilar: El pequeño conejo
Proyecto para scripting de un videojuego

# Descripción del videojuego:
Titulo: "Bilar:El pequeño conejo"
Genero: Aventuras, plataformas
Descripción: Pilar es un pequeño conejo que vive en su casa con su mama, papa y sus hermanos un día mama cayo enferma, esta enfermedad solo podía ser curada por una flor especifica en lo alto de una montaña, Entonces Pilar quien se dispone a ir a por la flor emprende una aventura
